Anti-pattern team minh de vuong nhat la de small files tich tu trong Bronze/Silver ma khong co lich compact/optimize ro rang. Luong event/LLM log thuong di theo micro-batch hoac streaming, nen moi lan ghi chi tao mot file nho; ban dau nhin van on vi query chua lon, nhung sau vai ngay transaction log va file listing phinh ra, filter pushdown kem hieu qua, va moi truy van Gold deu tra gia bang latency.

Bai NB2 cho thay cung mot predicate nhung sau compact + Z-order, so file can doc giam manh va query nhanh hon. Vi vay trong production, minh se dat contract cho tung layer: Bronze uu tien ingest on dinh, Silver co job compact theo kich thuoc/so file, Gold partition theo ngay va toi uu cot hay filter. Quan trong nhat la theo doi numFiles, file size, query latency nhu metric van hanh, khong doi den luc dashboard cham moi sua.
